👤 Roles (Agents)
通用执行单元，被 Skill / Orchestration 注入 context 后 dispatch。每个 Role 只有一个 ROLE.md。
谁调用 Role？
wyze-smart-lock → implementer / reviewer / kb-updater
wyze-plugin-creation → implementer / reviewer / host-integrator
⚡ implementer
代码生成。接收 CODING_STANDARDS + PROJECT_INFO + KNOWLEDGE_FILES + TASK + TARGET_FILES，输出代码文件。
🔍 reviewer
代码审查。支持三种 MODE：spec（单批规范）/ unified（统一核查）/ cross-batch（跨批一致性）。MAX_ROUNDS 可配。
📝 kb-updater
知识库更新。接收 CHANGED_FILES + KB_FILES + KB_STANDARDS，按映射规则更新对应知识库文件。
🏠 host-integrator
宿主工程集成。处理 Podfile/Gradle 引用、deviceModel 注册、pod install、编译验证。
📡 dispatcher
任务分发。将复杂任务拆分并分配给合适的 Role 执行。
🎯 orchestrator
流程编排。管理多步骤任务的执行顺序和状态流转。
🔗 MCP Servers
MCP 协议服务，为 Skill / Orchestration 提供外部数据源接入。
🔍 knowledge-rag-mcp
Node.js 实现的知识搜索服务，支持 stdio（默认）+ HTTP/SSE（团队共享）双模式。

⚙️ 基础设施
安装、同步、卸载三个脚本 + 配置模板。symlink 模型驱动，源头唯一。
bin/ — CLI 工具
📄 wyze-common.sh
共用函数库。install_symlinks_to_clients / relink_skills_with_symlinks / relink_mcp_servers 核心函数。
📄 wyze-sync
同步命令。git pull/push + 重建客户端 symlink。
wyze-sync 正向同步
wyze-sync other@wyze.com 导入他人 skill
📄 wyze-uninstall
分级卸载。删 symlink，可选保留 private，可选删 mcp-config / 仓库。
根文件
📄 install.sh
一键安装入口。依赖检查 → 建 symlink → 写 per-user 配置 → 装命令工具。重装用 wyze-install。
📄 mcp-config.template.json
MCP 配置模板。合并到 ~/.copilot 与 ~/.claude，per-user 含 API key。
📄 lsp-config.template.json
LSP（Language Server Protocol）配置模板。LSP 是一种让编辑器理解代码语义的协议 — 提供跳转定义、自动补全、错误提示等能力。此模板按选定语言生成对应的 LSP 配置，使 AI 编程工具获得与 IDE 相同的代码理解能力。
📄 CLAUDE.md
Claude Code 项目指令。结构、命令、约定。
