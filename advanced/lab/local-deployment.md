## 概述

本文介绍如何在本地运行开源大语言模型，覆盖 Ollama、llama.cpp、vLLM 等主流方案。

## 为什么要本地部署

- **隐私**：代码和数据不离开本机
- **成本**：无 API 调用费用，长期使用更划算
- **离线**：无网络环境也能使用
- **定制**：可加载微调后的私有模型

## 主流工具对比

| 工具 | 特点 | 适合场景 |
|------|------|----------|
| Ollama | 一键安装，极简 CLI | 个人开发、快速体验 |
| llama.cpp | C++ 推理，极致性能 | 资源受限、嵌入式 |
| vLLM | 高吞吐服务化部署 | 团队共享、API 服务 |
| LM Studio | GUI 界面，拖拽运行 | 非技术用户、快速验证 |
